# Rede.Compiler

Rede.Compiler is intended to compile programs written in the Rede programming language. It will consume tokens produced by Rede.Language from `.rede` source files and transform them into Rede bytecode (`.redebc` files).

The project is at an early stage; the compiler and its integration with Rede.Language have not yet been implemented.

## Requirements

- .NET 10 SDK

## Build

```sh
dotnet build Rede.Compiler.slnx
```
